**Leonida Legend** is an offline GTA VI trophy guide and tracker that runs entirely in your browser. It covers all 55 trophies with a written guide and source for each, a step-by-step roadmap to the platinum, clear flags on the trophies you can permanently miss, and filters by tier, type and completion. A spoiler setting keeps secret trophies hidden until you choose to reveal them, and your progress is saved locally (localStorage) with one-click export and import so you can back it up or move it between devices. No account, no network, no tracking — just you and the road to Leonida Legend.

## Run it

```sh
node serve.ts
```
